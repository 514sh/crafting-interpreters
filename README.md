# Crafting Interpreters

My implementations of the interpreters from [Crafting Interpreters](https://craftinginterpreters.com/).

[Crafting Interpreters](https://craftinginterpreters.com/) contains everything you need to implement a full-featured, efficient scripting language. You'll learn both high-level concepts around parsing and semantics and gritty details like bytecode representation and garbage collection. Your brain will light up with new ideas, and your hands will get dirty and calloused. It's a blast.
